# 원클릭업무포털

로그인된 Edge 세션을 이용해 나이스와 K-에듀파인의 업무 입력 화면까지 이동하는 Windows 데스크톱 프로그램입니다.

## 설치

GitHub의 **Releases**에서 최신 `Setup.exe`를 내려받아 설치합니다.

설치형 프로그램은 시작할 때 GitHub Release의 새 버전을 확인합니다. 새 버전이 있으면 자동으로 다운로드하고 적용한 뒤 다시 실행합니다.

## 사용 순서

1. 프로그램에서 `로그인`을 누릅니다.
2. 열린 Edge에서 업무포털 로그인과 인증서 인증을 직접 완료합니다.
3. 프로그램에서 해당 Edge 창을 선택하고 `연결`을 누릅니다.
4. 프로그램이 업무포털에서 `나이스`와 `에듀파인` 항목을 찾아 미리 열고 브라우저를 최소화합니다. 항목을 찾지 못하면 선택한 교육청의 공식 주소로 새 탭을 엽니다.
   - 업무포털 공지창이 열려 있으면 `1주일동안 열지 않기`를 선택하고 자동으로 닫습니다.
   - 나이스와 K-에듀파인 공지사항 안내창이 열려 있으면 닫기 버튼을 찾아 자동으로 닫고 업무 이동을 계속합니다.
   - 나이스에서 `정보보호를 위해 시스템을 종료합니다` 안내창이 나타나면 `확인`을 누르고 세션 종료 상태로 안내합니다. 실행 중이던 업무 요청은 재로그인 후 연결하면 이어서 실행합니다.
   - 공지창이나 닫기 버튼을 찾지 못해도 오류로 중단하지 않고 다음 준비 단계로 진행합니다.
   - K-에듀파인에 처음 접속할 때 필요한 로컬 네트워크 접근 권한을 자동으로 부여하고, 전용 Edge 프로필에서 선택한 교육청 공식 주소의 WXSClient 실행을 허용합니다.
5. `나이스`, `복무`, `출장`, `에듀파인`, `기안`, `품의` 버튼으로 필요한 화면을 엽니다.
   - 나이스에서 다른 업무 탭을 사용 중이어도 `복무`와 `출장`은 기본메뉴로 전환해 대상 화면을 찾으며, 기존 업무 탭은 닫지 않습니다.
6. 설정에서 세션 자동 연장을 켜면 업무포털의 `세션 시간 초기화` 버튼과 실제 `/bpm_lgn_lg00_102.do` 요청 완료를 확인합니다. HTTP 성공 응답을 받은 경우에만 업무포털 연장 성공으로 기록하며, 완료 여부를 알 수 없는 요청은 다시 보내지 않고 화면 확인을 안내합니다.
   - 나이스는 사이트 자체 jQuery의 `/sessionExtension.do` 요청과 프로그램 요청을 하나의 진행 상태로 공유해 중복 요청을 막습니다. 연장 요청이 2분 넘게 멈추면 기존 요청을 취소하고, 취소 완료를 확인한 뒤 1분 후 재시도합니다. 취소 완료가 불명확하면 중복 전송하지 않습니다. 실제 `Y` 응답을 확인한 경우에만 화면 타이머를 초기화합니다.
   - K-에듀파인은 Nexacro의 공식 `/naa/cmmn/cmmn/sessionCheck.do` 요청과 콜백을 사용하고, 서버 생존 응답이 `Y`일 때만 사용시간을 초기화합니다. 5분 넘게 요청 종료를 확인할 수 없으면 자동 재전송을 멈추고 화면 확인을 안내합니다. 나이스와 K-에듀파인의 `N` 응답은 즉시 재로그인 상태로 안내합니다.
   - 프로그램 실행 중 Windows의 자동 유휴 절전을 막습니다. 전원 계획은 변경하지 않으며, 사용자가 직접 실행하는 절전과 화면 잠금은 그대로 동작합니다.
   - 업무포털·나이스·K-에듀파인을 각각 확인합니다. 한 시스템이 로그아웃되거나 응답하지 않아도 나머지 시스템의 감시와 브라우저 연결은 계속 유지합니다. 안내창은 비모달로 표시되므로 닫지 않아도 다음 점검이 계속됩니다.
   - 서버의 보안 정책에 따른 로그아웃까지 무효화하지는 않습니다. 재로그인이 필요하면 해당 시스템만 대기 상태로 두며, 실제 복구를 확인한 뒤 대기 중인 업무를 한 번 이어서 실행합니다.
7. 다른 지역 사용자는 설정에서 소속 교육청을 선택한 뒤 새 로그인 창을 엽니다.
   - 저장한 소속 교육청은 프로그램을 종료했다 다시 실행해도 유지됩니다.
8. 내용을 확인하고 입력한 뒤 최종 상신 또는 결재 요청은 사용자가 직접 실행합니다.

## 다른 프로그램에서 업무 화면 열기

바탕화면 바로가기나 다른 프로그램에서 다음 주소를 열면 해당 업무 버튼과 같은 화면 이동을 요청할 수 있습니다.

| 주소 | 업무 |
| --- | --- |
| `oneclickportal://nice` | 나이스 |
| `oneclickportal://leave` | 복무 |
| `oneclickportal://trip` | 출장 |
| `oneclickportal://edufine` | 에듀파인 |
| `oneclickportal://draft` | 기안 |
| `oneclickportal://purchase` | 품의 |

명령줄에서는 `OneClickPortal.exe --task=leave` 형식도 사용할 수 있습니다. 프로그램이 꺼져 있으면 실행 후 요청을 처리하고, 이미 실행 중이면 기존 창으로 요청을 전달합니다. 브라우저 연결 전 요청은 연결이 완료된 뒤 이어서 실행합니다.

## 지역 및 창 설정

- 프로그램은 작업표시줄 버튼 대신 오른쪽 알림 영역(시스템 트레이)에 아이콘으로 표시됩니다. Windows 설정에 따라 `^` 숨겨진 아이콘 목록에 들어갈 수 있습니다.
- `X` 또는 Alt+F4는 창만 숨깁니다. 연결과 설정된 세션 자동 연장은 유지되며, 자동 유휴 절전 방지도 계속 적용됩니다.
- 트레이 아이콘을 클릭하거나 프로그램을 다시 실행하면 기존 창이 열립니다. 완전히 종료하려면 트레이 아이콘을 오른쪽 클릭하고 `완전히 종료`를 선택합니다.
- 서울·경기·경남·부산·대구·대전·경북·세종·울산·인천·광주·전남·전북·충남·충북·강원·제주를 지원합니다.
- 선택한 교육청에 맞춰 업무포털, 나이스, K-에듀파인 주소를 자동으로 사용합니다.
- 기존 사용자와 설정값이 없는 사용자의 기본 교육청은 전북입니다.
- `프로그램을 항상 위에 표시`는 기본적으로 꺼져 있으며 설정에서 켜거나 끌 수 있습니다.
- 메인 작업창과 설정창은 Windows 모니터별 DPI 배율에 맞춰 크기와 글자를 함께 조정합니다.
- 서로 다른 배율의 모니터 사이로 창을 이동해도 화면 안에 보이도록 위치를 보정합니다.

## 안전 원칙

- 로그인과 인증서 선택은 사용자가 직접 수행합니다.
- 프로그램은 최종 상신·결재 요청 버튼을 자동으로 누르지 않습니다.
- 브라우저 권한 설정은 원클릭 업무포털의 전용 Edge 프로필 안에서 선택한 교육청의 K-에듀파인 주소와 `wxsclient` 프로토콜에만 적용합니다.
- 로그인 정보, 인증서 암호, 개인정보와 세션 토큰을 저장하지 않습니다.
- 사용자 수 집계는 로그인 없이 익명 설치 식별자의 SHA-256 해시와 앱 버전만 전송합니다.
- 기본 사용 통계는 하루 한 번, 현재 사용자 신호는 한국 시간 오전 7시~11시에만 30분 간격으로 전송합니다.
- 이름, 이메일, 학교, 나이스·K-에듀파인 화면 내용은 사용 통계에 포함하지 않습니다.
- 익명 사용 통계는 설정에서 언제든지 끌 수 있습니다.

## Firebase 사용 통계

Firebase 프로젝트 ID는 `oneclickportal`입니다. Cloud Function은 새 설치 수와 날짜별 활성 설치 수를 Cloud Firestore에 기록합니다.

설정창에는 항상 `현재 n명의 사용자가 원클릭 업무포털을 사용 중입니다`로 표시합니다. 내부 집계는 오전 7시~11시 동안 최근 40분 인원을 사용하고, 그 밖의 시간에는 가장 최근 오전 11시 집계값을 유지합니다.

- 전체 설치 수: `usageStats/global.totalInstallations`
- 날짜별 활성 설치 수: `usageDaily/{yyyy-MM-dd}.activeInstallations`
- 익명 설치별 최초·최근 실행: `anonymousInstalls/{SHA-256 해시}`

로그인 없는 집계이므로 한 사람이 여러 PC에 설치하거나 레지스트리를 초기화하면 별도 설치로 계산됩니다. 또한 공개 HTTP 엔드포인트 특성상 이 수치는 정확한 개인 수가 아니라 활용 추세를 보는 추정치입니다.

백엔드 테스트와 배포:

```powershell
cd .\functions
npm install
npm test
cd ..
npx firebase-tools deploy --only firestore:rules,functions
```

## 로그

현재 수정본은 Windows 잠금·해제와 절전·복귀, 시스템별 세션 확인 결과, 공식 연장 요청의 HTTP 또는 서버 응답 상태를 기록합니다. 프로그램이 실행되는 동안 Windows `SYSTEM_REQUIRED` 요청으로 자동 유휴 절전을 억제하고 종료할 때 해제합니다. 사용자가 직접 실행하는 절전과 화면 잠금, 조직의 전원 정책 및 서버의 강제 로그아웃 정책은 그대로 적용됩니다. 이미 만료된 세션의 복구에는 재로그인이 필요합니다.

세션 자동 연장이 켜져 있으면 지원 브라우저에서 매분 업무포털·나이스·K-에듀파인 탭의 백그라운드 실행 상태를 활성화한 뒤 각 시스템의 공식 연장 상태를 확인합니다. 이 동작은 브라우저 창을 앞으로 가져오거나 업무 화면을 새로고침하지 않습니다. 연장 성공은 서버 응답으로만 판정하며, 응답이 없는 동안 세션 유지가 보장되지는 않습니다.

```text
%LOCALAPPDATA%\OneClickPortal\logs
```
